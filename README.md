# 🇵🇰 Pakistan Stock Exchange (PSX) Predictor

A high-performance, web-based stock market prediction and analysis application for the Pakistan Stock Exchange. This project uses **Linear Regression** to predict future stock prices based on historical trends and provides comprehensive **Technical Analysis** indicators.

## 🌟 Key Features

- **🚀 Future Price Prediction**: Predicts stock prices for the next 7 to 90 trading days using Scikit-Learn's Linear Regression.
- **📊 Interactive Charts**: Visualizes historical OHLC (Open, High, Low, Close) data and Volume using Plotly Candlestick charts.
- **📐 Technical Indicators**:
    - **RSI (Relative Strength Index)**: Identifies overbought and oversold conditions.
    - **MACD (Moving Average Convergence Divergence)**: Analyzes trend momentum and potential reversals.
    - **Bollinger Bands**: Measures market volatility and price levels.
    - **Moving Averages (SMA 20, 50, 200)**: Highlights long-term and short-term trends.
- **📋 Real-time Signals**: Generates automated **Buy / Sell / Hold** recommendations based on predicted price changes.
- **💾 Data Export**: Allows users to download both historical data and prediction results in CSV format.
- **🔌 Offline Support**: Includes a built-in data generator to work without a live internet connection if needed.

## 🛠️ Technology Stack

- **Frontend**: [Streamlit](https://streamlit.io/) (Pure Python UI Framework)
- **Data Analysis**: [Pandas](https://pandas.pydata.org/), [NumPy](https://numpy.org/)
- **Machine Learning**: [Scikit-Learn](https://scikit-learn.org/) (Linear Regression)
- **Visualization**: [Plotly](https://plotly.com/python/)
- **Data Source**: Local CSV Data (with fallback/script for YFinance)

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/Shifrozy/Pakistan-Stock-Exchange.git
cd Pakistan-Stock-Exchange
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Generate Offline Data (Optional)
If you want to use the app without an internet connection or if live APIs are restricted, run the data generator:
```bash
python generate_data.py
```

### 4. Run the Application
```bash
streamlit run app.py
```

The app will be available at `http://localhost:8501`.

## 🤖 How the Prediction Works

The application uses a **Linear Regression** model trained on historical closing prices.
1. **Feature Engineering**: It creates features using lagged prices (past 20 days), moving averages (5, 10, 20), momentum, and trend indicators.
2. **Training**: The model is trained on 80% of the historical data and validated on the remaining 20%.
3. **Recursive Forecasting**: Future prices are predicted one day at a time, where each prediction is used as an input for the next day's forecast.
